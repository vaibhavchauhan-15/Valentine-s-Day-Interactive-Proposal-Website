# 💝 Valentine's Day Interactive Proposal Website

A romantic, interactive one-page website designed to ask someone special to be your Valentine through playful questions, smooth animations, and beautiful transitions.

## ✨ Features

- 🎁 **Interactive Gift Box Opening** - Start with a beautiful animated gift box
- 💕 **Playful Yes/No Question** - The "No" button playfully moves away when hovered
- 🎬 **Multiple Date Options** - Choose from 4 romantic date ideas with unique animations:
  - Romantic Movie Date 🎬
  - Romantic Dinner Date 🍽️
  - Romantic Long Drive 🚗
  - Romantic Camping Date ⛺
- 💖 **Beautiful Animations** - Smooth transitions and delightful animations throughout
- 📱 **Mobile-First Design** - Optimized for all devices
- 🎨 **Modern UI** - Glassmorphism effects, gradient backgrounds, and romantic color palette

## 🚀 Quick Start

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and visit the local URL shown in the terminal (usually `http://localhost:5173`)

### Build for Production

```bash
npm run build
```

The built files will be in the `dist` folder, ready to deploy!

## 🌐 Deployment

This project can be easily deployed to:

- **Vercel** (Recommended) - Just connect your GitHub repo
- **Netlify** - Drag and drop the `dist` folder
- **GitHub Pages** - Use the built files

## 🎨 Customization

You can easily customize the website:

- **Colors**: Edit the color values in [tailwind.config.js](tailwind.config.js)
- **Messages**: Update the cute messages in [src/components/ValentineQuestion.jsx](src/components/ValentineQuestion.jsx)
- **Date Options**: Modify the options in [src/components/DateOptionsScreen.jsx](src/components/DateOptionsScreen.jsx)
- **Final Message**: Customize the final message in [src/components/FinalScreen.jsx](src/components/FinalScreen.jsx)
